# ProofGuard

Week 4 Business Bending project by Emiliano Carballido.

ProofGuard reviews employer-facing claims against one simulated, structured Proof-of-Skill record. It preserves candidate control over sharing, correction, and expiry, and blocks Shadow Clause violations such as employability, potential, personality, aptitude, ranking, or destiny claims.

- Live site: https://proofguard-emiliano-week4.ecarba27.chatgpt.site
- Demo data: fictional and clearly labeled
- Storage: none; candidate controls are in-memory
- Tests: `pnpm test`
- Local run: `pnpm install && pnpm dev`

See `docs/PACKET.md`, `docs/IMPLEMENTATION_PROMPT.md`, `docs/TEST_LOG.md`, and `docs/PERSONA_TEST.md` for the required project evidence.
